文档与模板

.xlsxExcel

添加自己的周报、表格等模板，新建时保留原有内容和格式。

应用与终端

用指定应用打开文件

添加常用应用，从右键菜单打开文件。也能在终端中打开文件所在的文件夹。

终端

文件名与路径

拷贝完整路径、文件名，或不含扩展名的名称。

ZIP 压缩与解压

把文件压缩为 ZIP，或将 ZIP 解压到当前文件夹。

计算和比较文件哈希

计算 SHA-256、SHA-1 或 MD5，或比较两个文件的哈希值。

查看隐藏文件

从右键菜单切换访达的隐藏文件显示状态。
